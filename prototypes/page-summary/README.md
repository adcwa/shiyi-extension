# 点译 · 网页总结交互原型

2026-11-03 · 先体验交互，再决定插件改版

## 打开与体验

打开同目录的 [index.html](index.html)，或通过本地静态服务器打开本目录。这是网页原型，不是可安装的浏览器扩展包。

识别、模型连接、总结与翻译使用固定示例，**不连接真实模型、不发送网页、不消耗模型额度、不保存 Key**。请勿填写真实密钥。复制、图形渲染与文件导出为实际可用操作。

推荐按这条路径体验：

1. 点击“开始总结”：先出现主题识别，再逐步输出技术总结；左侧网页原文保持不变。
2. 生成时向上阅读，内容不会强制跳回底部；点击“停止生成”，已有文字仍可复制和导出。
3. 完成后切换“制品”，体验流程图的预览／源码、代码复制、表格与公式。
4. 点击侧栏右上角的设置图标：总结与翻译各自配置；总结不接受 `qwen-mt-*` 专用翻译型号。连接结果也是本地演示，不代表服务或型号已经验证。
5. 改选新闻、专业或调研预设：原结果不会自动重跑；点击“重新总结”并明确确认后才重新生成。
6. 切换“网页翻译”可体验双语、仅译文、恢复原文与示例本地加载；词库入口支持搜索、编辑、删除和撤销。

顶部“体验场景”用于查看首次配置、额度不足、空白网页与切换网页的状态，不是正式插件的运行开关。

## 演示与实际能力

| 可以实际体验 | 仍是固定示例 |
| --- | --- |
| 侧栏开关、任务与预设切换、停止和结果保留 | 网页正文来自随原型附带的示例文章，不读取任意浏览器标签页 |
| Markdown、代码、表格、Mermaid 与公式渲染 | 自动识别固定将示例文章归为技术类，不是真实分类判断 |
| 剪贴板复制和文件下载 | 总结与翻译文字、流速、连接成功及额度错误均为模拟 |
| 提示词编辑、词句搜索／编辑／删除／撤销 | 提示词和补充关注点不改变固定输出；目标语言菜单不会产生各语言译文 |

划词后点击语言胶囊会读取已有示例释义，或新增一条可编辑的示例释义；仅选中或切换语言不发起生成。超过 140 字的选区只提示转到整页阅读，没有实现独立的长选区翻译。黑名单和词句改动只影响当前原型页面，不代表跨网站、跨刷新存储已经接入。

## 总结方式

| 预设 | 重点 |
| --- | --- |
| 自动识别 | 先识别主题与类型，再使用相应预设；不等同于逐句翻译 |
| 技术总结 | 问题、机制、实现流程、代码、依赖和适用边界 |
| 新闻总结 | 事件与事实、时间和主体、引用观点、缺失和待核实信息 |
| 专业分析 | 论点、证据、影响、条件、风险与分析建议 |
| 调研分析 | 研究问题、资料与方法、发现、证据局限及待核实项 |

调研分析仅依据当前网页，不暗示已进行额外联网调研。原型的新闻预设遇到技术文章时明确指出来源不是新闻，不编造事件。

## 渲染、复制与导出

| 内容 | 预览与复制 | 导出 |
| --- | --- | --- |
| 总结全文 | Markdown 排版、复制原始 Markdown | `.md`、独立可阅读 `.html` |
| 代码 | 等宽显示、复制代码 | 对应语言文件，如 `.js` |
| 表格 | 表格阅读、复制 Markdown 源码 | `.csv`、`.md` |
| Mermaid 图 | SVG 图形／源码切换、复制源码 | `.svg`、`.mmd` |
| 公式 | MathML 排版、复制 LaTeX | `.tex` |

停止后的部分结果也可导出，会注明“部分结果”；未闭合的代码或图形块会先按源码显示。全文 HTML 导出是独立可阅读文档，不包含可执行脚本；Markdown 不执行原始 HTML，图形使用 strict 安全模式，公式使用不信任 HTML 的 MathML 输出。本轮不包含可执行 HTML 或交互图表。

## 从原型接入真实插件

原生产插件、权限、密钥、词库及安装目录没有被这份原型修改。当前侧栏是网页中的布局，不是浏览器原生侧栏。真实接入仍需实现独立的总结模型配置、正文读取、主题识别请求、真实 SSE 输出与取消处理，以及浏览器原生侧栏和所需权限。

未来真实接入可参考 [Chrome sidePanel 官方文档](https://developer.chrome.com/docs/extensions/reference/api/sidePanel) 和 [Edge 侧栏官方文档](https://learn.microsoft.com/en-us/microsoft-edge/extensions/developer-guide/sidebar)。权限、用户手势触发与支持版本需按目标浏览器核对。

自动识别计划分成两步：首先得到主题／类型，再按该类型预设发起总结流。手动预设直接进入总结流。读取仅限当前页已加载的可读正文，排除表单、输入内容、隐藏区和插件自己的 UI；正文变化或切换网页不自动重发请求。超长网页需要明确读取范围和分段策略。

正式实现还需验证分离的凭据存储、原生侧栏的标签页绑定、真实厂商 SSE 错误和取消、长文上下文边界、匹配本地结果恢复，以及关闭／切换页面后的请求处理。本轮原型不代表上述接入已经完成。

## 文件与离线边界

`vendor.js` 将 Markdown、Mermaid 与公式渲染器放在本地，不依赖 CDN 或远程字体。依赖许可见 [LICENSES.txt](LICENSES.txt)。图形与公式可在离线打开时渲染；浏览器可能限制本地文件的自动剪贴板权限，失败时可选中文本或查看源码后手动复制。界面的“获取 Key”和额度帮助是外部链接，只有主动打开时才访问对应网站。

演示状态保存在当前页面内存，刷新会回到初始示例；“关闭再打开侧栏”保留本次内容。“刷新并加载本地结果”只演示已有译文重绘，不会真正刷新页面，不是跨刷新持久化验收。“长期记住密钥”只展示选项，不保存 Key。
