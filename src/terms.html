使用说明

下面是当前本地安装版的使用边界，帮助你开始前了解连接、费用与数据保存方式。

更新日期：2026 年 11 月 4 日

本地安装与升级

点译以 Chrome / Edge 扩展安装包交付，尚未发布到浏览器商店。下载后先解压，再从扩展管理页加载。新安装使用固定标识，换目录加载保持同一身份。已有旧版请运行随包“升级点译”保留原目录及旧身份，然后重新加载原插件。不要先卸载；卸载会清理本地数据。工具只备份旧程序，不能替代词库与阅读知识备份。

模型由你连接，费用由服务商结算

插件没有内置共享密钥、服务套餐或代扣流程。你负责选择模型服务并提供有效 Key。模型权限、地域、额度、价格、计费方式及账户规则以相应服务商为准。测试连接、新翻译、主动开启后的后台网页总结、日周月年和专题回顾，以及主动重译／重新总结都可能产生模型用量。黑名单除外；已有资料按输入版本复用。

备用与本机登录

默认连接的受控故障可触发已勾选的备用连接，相同资料可能由其他服务商处理并产生用量。本机 Codex 使用其已有账户的权限与额度，ChatGPT 登录不等同于 API Key 按量计费；使用前请核对适用规则。当前本机助手支持 macOS / Linux，首次需要独立安装。

已存释义不等于每次重新判断

再次遇见词句时，点译提示的是之前保存的释义。相同词句在不同语境可能有不同含义，可以在词句库编辑或删除。当前不会自动维护同一个词的多个义项。

把模型结果当作阅读辅助

翻译和总结可能遗漏细节或出现错误。涉及重要判断时，请核对原文。单页总结基于已加载正文及必要的相关阅读上下文；周期与专题回顾基于本地已存资料。它们不代表完成了额外联网检索或专业核验，也不能把访问网页等同于已掌握或已完成工作。

可用范围与备份

当前主要处理普通网页的主文档文字。浏览器内部页、商店、内置 PDF、图片文字和部分框架内内容暂不支持。词库、轨迹与回顾没有云端副本，卸载扩展或清理数据前，请先导出备份。自动总结默认关闭，手动总结不受影响；开启后默认每日 18:00 汇总，浏览器完全退出或设备关机时无法准点执行，恢复后补办缺失周期。
