# 点译 · 划词工具条设计提案

2026-11-03 · 待用户选择，尚未修改插件。

目标：极简、易懂，支持直接选择目标语言，并保持「翻译成功后收藏」及语境设置能力。

## A · 单行直达（推荐）

布局：译成［中文⌄］｜［翻译并收藏 →］［更多］［关闭］。

语言与动作分开，选中后即可看懂。移除按钮内重复翻译图标，使用清楚的文字；语境开关收进更多。适合默认中文、偶尔换语言的日常阅读。

## B · 双行清晰

上行：目标语言［简体中文⌄］［关闭］。下行：［附带语境］［翻译并收藏 →］。

设置全部可见，减少寻找和猜测，适合常调整语言和语境。纵向空间更大，但宽度更短。

## C · 一键胶囊

布局：［译成中文并收藏｜⌄］［更多］［关闭］。

把语言写进主按钮，点击文字立即翻译，点击右侧箭头切换语言。主操作集中，适合长期使用同一目标语言。语境放在更多中。

## 三个方案的共同交互

- 目标语言提供中文、英语、日语、韩语、法语、德语、西班牙语；默认沿用已配置的目标语言，后续记住用户选择。
- 选择语言只改变本次及后续划词的目标语言；用户点击翻译才发送请求，不因切换语言自动消耗额度。
- 沿用已保存的语境偏好；更多中开启语境时显示状态点，并说明会发送相邻一句。
- 已有对应语言的本地释义时，动作改为「查看释义」，避免重复请求。长选区仍沿用按段翻译、不自动收藏的业务规则。
- 保留 × 与 Esc 关闭；支持键盘操作、明确焦点、减少动画，悬浮状态不改变布局。
- 预览是独立 HTML，示例译文为本地演示，不读取密钥、不调用模型，不修改安装包、词库或配置。
