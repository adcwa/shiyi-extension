可行性与实现方式

方案可行。实现为「本地标签树与片段 ID → 纯文本翻译 → 按 ID 重建标签」。去标签只发生在发给模型的数据中，原网页的元素和事件保持原位。不能把整段压成没有边界的字符串后按字符位置猜标签，因为翻译会改变长度和语序。

复用现有的稳定片段 ID、对齐校验及 record.values，本地新增 ShiyiInline 模块记录嵌套结构、来源节点及链接绑定。模型继续只返回文字与 ID，HTML、链接属性和 DOM 引用不进入模型协议。新增的译文通过 createElement／createTextNode 生成，不解析模型返回的 HTML。

标签支持

范围 处理
a 重建真实链接，地址来自原节点；支持普通文案、URL 文案、相对地址、锚点、mailto、tel、target 与受控 rel／download
b、strong、i、em 保留加粗、斜体与嵌套层级；兼容历史 bold／blod 写法并映射到 b
font、span、small、big 保留字体与局部字号关系；font 的 face／size 等属性本地恢复，译文颜色及字号规则仍优先
code、kbd、samp、var、tt 内容作为保护片段原样显示，不交给模型改写；保留等宽字体等格式
u、s、strike、del、ins、sub、sup 保留下划线、删除线、修订与上下标
abbr、acronym、q、cite、dfn、time 保留文本语义及受控的 title、datetime 属性
bdi、bdo、ruby、rt、rp 保留相应文本结构与方向信息
br、wbr 本地保留换行及断词位置，不依赖模型输出标签

共 35 种受控文本标签，另有 2 个历史加粗别名。未知文本容器采用普通 span 承接文字，避免触发自定义元素构造；脚本、表单、资源元素等不复制。

阅读效果与交互

双语译文仍按块追加，不增加底色或侧线。每个重建节点按其来源计算字号减 2px，保留字体、字重、斜体、上下标及行距关系；颜色统一继承用户设置的译文颜色，避免原 font.color 覆盖配置。仅译文继续修改原 Text.data，保持原字号和节点身份。

译文链接有下划线与键盘焦点。普通左键及键盘激活转给仍有效的原链接节点，以复用页面已有的点击／路由监听；中键、组合键、右键菜单使用重建链接的原生 href。紧凑导航文字仍放在原链接内部，不生成嵌套 a。

程序调用 click() 产生的事件不能伪装成 isTrusted=true；对严格依赖可信事件的特殊脚本控件，原文入口始终保留。浏览器事件说明

映射和缓存

现有页面暂存已有片段 values、节点路径与链接目标指纹。本次不改变数据库结构、模型接口、批次和并发参数。结构匹配的 v0.8.0 缓存可以直接结合当前 DOM 恢复标签，无需调用模型。

新支持的保护标签若与旧记录缺少对应片段，只在用户主动「翻译新增内容」时处理缺失块。URL 形式的链接文案按原文字面显示，即使旧缓存里的模型结果改过域名，也不会改用错误地址或显示错误域名。

本地映射还检查文本节点和标签层级、换行及链接属性。页面改变或移除链接后，旧译文先撤下；用户刷新新增内容时，复用文字缓存并重新绑定当前链接。修改 font 属性、主题、调色板或视口尺寸则原位更新格式，保留译文，不自动请求模型。

结构重建边界

只从当前网页读取允许的导航属性和文本格式。ID、任意 class、原始 style、on*、表单与资源标签不会整体克隆；javascript、data 等不作为译文链接。模型输出的 HTML 按文字显示。

格式不是整段 cloneNode(true)，因为它会复制不需要的属性，并且不会复制 addEventListener 绑定的事件。DOM 说明

只有完整译文字符串、没有片段映射的历史长词库释义继续使用旧显示，原文链接仍可操作；不会猜测译文中的链接位置。按段和整页阅读使用本次通用映射。
