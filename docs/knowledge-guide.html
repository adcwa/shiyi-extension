点译 v0.14.2 · 阅读轨迹与周期回顾

2026-11-04 · 正式插件功能

网页读过之后，摘要、来源和自己的想法可以一起留下来。自动总结默认关闭。手动总结始终可用；开启弹窗顶部的「自动总结」后，点译才会自动保存符合条件的网页正文，在后台使用独立的总结模型归纳，不开侧栏也会处理。打开侧栏直接读取结果，在「我的轨迹」检索、整理，在「阅读回顾」查看日、周、月、年和专题分析。

开始使用

  1. 将 v0.14.2 安装包解压；已有旧版运行“升级点译”保留原目录与原身份，再在扩展管理页重新加载原插件。不要卸载旧扩展。
  2. 在「模型库」添加一次连接，在「总结设置」直接选择已保存的通用模型与备用；翻译可独立选择同一或其他连接，选同一连接时共用 Key。
  3. 需要后台处理时，先在弹窗顶部开启「自动总结」，再正常浏览网页。已打开且可读取的网页，以及此后访问的普通 HTTP(S) 页面，会自动登记、采集正文并排队总结；不要求先打开侧栏。
  4. 点击插件弹窗最上方「总结当前网页」，或网页右键「点译 → 总结当前网页」。侧栏按标签页独立打开，已有结果直接显示，进行中的任务继续流式显示。
  5. 在管理界面进入「我的轨迹」和「阅读回顾」。时间、时区及各层回顾提示词在「总结设置 → 定时回顾」。

总结会使用你配置的模型额度。开启自动总结后，普通页面自动采集即可能调用模型，每日和周期汇总也会调用；已有摘要、复制、导出、打开侧栏和相同输入的重复调度会尽量复用。没有配置总结模型时先保存资料并显示等待，连接恢复后处理。自动总结默认关闭，升级旧版同样默认关闭；从插件弹窗顶部或总结设置页开启。关闭会停止自动网页总结和定时回顾，保留已有内容，未开始的旧自动任务暂停，不因换 Key、刷新或重启恢复。关闭时仅在本地登记访问标题、地址等元信息，不自动提取正文。手动总结和手动生成回顾照常可用，不会顺带打开自动总结。开启后从当前打开网页及后续访问处理，不批量重跑旧暂停历史；重新访问相应网页可继续其任务。停用网站请使用黑名单或浏览器的网站访问权限。

采集范围与上下文

只处理主文档已经加载、可读取的主要正文，优先文章或主内容区域，保留正文中的代码、表格和章节。最多 60,000 字符，截取时显示提示；不自动滚动或补抓历史网页。

不读取表单输入值、密码、可编辑草稿、隐藏区、Cookie 或登录令牌。导航、侧边栏和插件界面不作为正文。仅译文模式仍提取原始文本。浏览器内部页、扩展商店、内置 PDF、图片文字、iframe 和 Shadow DOM 暂不支持。

从升级时当前可读取的标签页和后续访问开始记录，不扫描浏览器已有历史。每次导航或刷新保留访问时间；相同地址和正文共用快照，相同正文及总结配置复用摘要。正文变动或主动重新总结会产生新版本。

请求可包含标题、正文、少量直接相关阅读摘要及用户备注、项目和标签；关联来源 ID 一起保留。它不会把全部浏览历史拼进单页请求，也不把一次访问当作已经读完或掌握。模型不额外联网调研。

展示来源地址保留常用文章 ID、分页等必要参数，移除认证、追踪和未知参数；涉及特殊地址时请在原网页核对。正文中本来可见的信息仍会发送到所选服务。

我的轨迹

按时间查看访问记录，可用关键词、日期、来源域名、项目和标签筛选；关键词也检索已保存的摘要。输入关键词后停止约 350 毫秒自动检索，输入法组词完成后才检索；日期、来源、项目、标签选择后自动更新，不需要点筛选。列表分页展示，右侧阅读摘要、制品、来源、请求尝试次数以及服务商明确返回的 Token 用量。

  • 阅读备注：为访问记录填写项目、标签和自己的想法，点击「保存备注」。未保存草稿不会被后台刷新覆盖；切换记录再回来仍保留，可以明确丢弃。
  • 来源与版本：从回顾进入对应页面摘要，再打开原网页；重新总结保留旧完成版本，便于比较。
  • 重新总结：使用已存原文重新请求，无需来源标签页仍然打开。资料尚未采集时需重新访问。
  • 清理：删除单条访问、当前筛选范围，或在「数据与隐私」清空全部轨迹与回顾。共用的原文在最后一次引用删除后清理；依赖被删资料或备注的摘要及回顾同时清理，防止旧任务写回。

轨迹、正文、摘要和任务使用独立的本地 IndexedDB，不受整页译文缓存的 7 天／50 页淘汰规则影响。它们保留到主动清理；没有云端副本或自动导入恢复。卸载、清空扩展存储或磁盘故障可能丢失数据，请定期导出。

日、周、月、年与专题

类型 主要输入 归纳重点
每日 当天页面摘要、阅读备注与来源关系 当天关注、事实依据、关联与待核对问题
每周 周一至周日的日结 持续主题、变化、重复问题与差异
每月 当月日结 阶段脉络、来源对比与知识积累
每年 自然年内月结 长期方向、主要变化与未解决问题
专题 当前筛选范围的已存摘要及备注 按主题、项目、来源、技术方案、待验证问题等维度分析

点击「生成回顾」即可按所选日期、周期和维度生成；相同输入复用已有记录。「重新总结」明确产生新版本。上层回顾保留原始页面来源链，月结不直接拼接跨月周报，避免同一资料重复计入不同月份。

资料过多时先分批整理证据再归纳。已采集页面仍在等待／生成时，回顾等待这些任务完成后再开始；失败或未取得正文的记录显示待补齐数量。没有有效资料则直接生成空记录，不调用模型编造内容。下层失败需先恢复相关任务，再重新生成回顾。

事实、原文观点和模型分析需要核对来源。模型输出是阅读辅助，尤其不能把访问轨迹等同于工作完成或能力评价。

每日 18:00 与补办

开启自动总结后，计划时间默认为每天 18:00，Asia/Shanghai；开关关闭时不注册每日自动任务。在「总结设置 → 定时回顾」调整时间与 IANA 时区，并保存；各阶段提示词也在这里配置。

按所选时区的自然日归档。18:00 生成截至当时的阶段回顾，晚间新资料仍属于当天；下一次调度或恢复运行时补齐新的日结版本，并更新受影响的已结束周期。周、月、年在周期结束后补办，周期最后一天到计划时间也可生成阶段回顾。

浏览器定时事件不能唤醒关机设备或已完全退出的浏览器。恢复运行会检查缺失周期，依据本地输入版本去重；不承诺离线时准点生成。仅时间经过、后台唤醒或重复定时事件，不会重新汇总没有变化的同一批资料。

后台队列与恢复

采集后先把原文快照和任务写到本地，再调用模型。采集完成后关闭网页不影响已保存任务；正文取得前关闭则只保留访问和状态。

后台逐项执行，实际请求按连接规则有界尝试。默认连接故障时，可尝试勾选的备用连接，每个最多一次；已经输出文字后保留部分结果，不自动从头重跑。服务异常可能暂停队列，在「我的轨迹」查看原因并恢复；失败记录可主动重试。

浏览器或后台在任务进行中退出时，保留已写入内容并标为中断，需主动重试，避免重启后重复计费；自动总结已开启时，已排队且未暂停的任务继续处理；关闭后不续办旧自动任务。存储失败会停止队列并说明原因，不把未落盘结果当成成功。

请求尝试次数来自实际请求边界，Token 只显示服务商明确返回的字段；没有返回则不估算，也不伪造费用。后台自动总结和分层整理均可能增加用量，费用仍以服务商账单为准。

黑名单与权限

黑名单按域名及子域名生效。停用网站不新增采集、不进入新模型任务，不显示该网站侧栏；在途任务取消，晚到结果不能写回。

历史记录不会因加入黑名单自动删除，但被停用来源及引用其上下文的摘要不会进入新的回顾或知识导出。需要彻底移除时，在「数据与隐私」清空轨迹与回顾。移出黑名单恢复之后的网页处理，不追溯抓取停用期间的历史。

请求开始前复核来源及相关阅读上下文的权限；浏览器收回网站访问权限后，不能通过本地上下文绕过限制。侧栏仍按标签页显示，后台自动总结不等于自动弹开所有侧栏。

复制与导出

摘要和制品支持独立复制／导出，沿用网页总结中的 Markdown、代码、表格、Mermaid 与公式操作。轨迹和回顾页顶部「导出知识」按当前筛选范围导出：

格式 用途
ZIP 知识包 Markdown + YAML、结构清单、JSONL 关系和 CSV 时间线；文件间可追踪
Markdown 可编辑的完整阅读文档，包含来源链接
HTML 独立阅读文档，渲染表格、代码、公式及 SVG 图，无脚本或远程依赖
JSON / JSONL 结构化访问、摘要、版本、来源、备注和关系，适合后续知识处理
CSV 访问时间线和整理索引，对公式触发值做转义

默认导出摘要和元信息，ZIP、JSON、JSONL 可明确勾选「包含已保存的完整原文快照」。ZIP 内有 manifest.json、每条摘要的 Markdown、visits.jsonl、documents.jsonl、summaries.jsonl、relations.jsonl 和 timeline.csv，筛选外的必要引用保留来源说明。版本和证据 ID 不依赖点译界面即可解析。

不导出 API Key、连接凭据、Cookie 或认证缓存。单批传输超过保护范围时提示缩小日期／项目范围，或取消完整原文后分批导出；不会静默截断知识文件。当前提供通用可解释格式，不承诺所有第三方知识库一键导入，也没有 Word 格式。

验证范围

使用最终安装 ZIP、隔离临时 Chrome 资料和真实本地 HTTP/SSE 服务验证后台采集、原生侧栏、本地存储、浏览器重启、定时事件、五种回顾、备注保护、制品和真实下载。没有使用付费厂家的 Key，也不读取用户真实浏览历史或认证文件。

Chrome 已实际安装验证；Edge 使用同一 MV3 包，尚未进行原生 Edge 验证。侧栏宽度由浏览器分隔线控制，物理拖动手势未在本轮自动化复验。详见验收记录。
