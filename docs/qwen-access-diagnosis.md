## 确认的原因

`qwen-mt-flash` 的请求已经到达阿里云。服务明确返回免费额度耗尽，公共域名进一步返回 `AllocationQuota.FreeTierOnly`，说明受“免费额度用完即停”限制。此次失败无需修改目标语言、批次或 MT 协议参数；更换 Base URL 不会解除额度限制。

三次请求均只发送 curiosity。最简请求只含 model、单条 user 消息及 source_lang／target_lang，排除了插件附加领域提示造成此拒绝的可能。没有取得成功译文，因此不能将这次诊断表述为真实翻译质量验收。

公共域名请求编号：`f9531ae1-9e43-9714-abb6-5a5ae42afff7`。完整脱敏记录在 verification/qwen-live-access-2026-11-03.json，包含诊断日期、耗时、地址、模型、状态及三个请求编号，不含凭据或认证头。

官方文档确认，免费额度用完即停启用后，额度耗尽返回 HTTP 403 / AllocationQuota.FreeTierOnly。[阿里云额度规则](https://help.aliyun.com/zh/model-studio/new-free-quota)

## 用户处理步骤

1. 在电脑端打开阿里云百炼控制台，确认选择北京地域及创建 Key 的账户／业务空间。
2. 打开“免费额度”页面，搜索 `qwen-mt-flash`，查看剩余额度、到期时间和“免费额度用完即停”。
3. 如果希望继续按量付费，在确认该模型计费后自行关闭此模型的用完即停限制，并确认账户余额足够；如不希望付费，保留限制，选择自己仍有可用额度的模型。
4. 等待控制台配置生效后，在插件点击“仅测试连接”；成功后再点击“连接并保存”。

关闭限制后，后续调用可能按量计费。此次诊断未代替用户充值、关闭限制、更换账户权限或改动任何云端设置。额度配置存在生效延迟，具体以[官方说明](https://help.aliyun.com/zh/model-studio/new-free-quota)和控制台状态为准。

## 地址与插件配置

公共地址可保留默认“通义千问”；专属域名选择“自定义服务”，粘贴控制台 Base URL，模型填写 `qwen-mt-flash`，鉴权保持 API Key（Bearer）。插件会补齐一次 `/chat/completions`，该型号仍走专用 MT 请求。

阿里云已提供业务空间专属域名，原公共域名仍可用。此次两个地址均已返回正常鉴权与额度响应，没有发现地址拼接错误。[官方端点与错误说明](https://help.aliyun.com/zh/model-studio/error-code)

## 插件修复

旧版只根据 HTTP 状态生成统一提示，丢弃服务端具体原因。v0.9.1 在有界读取后，只保留受控错误码和请求编号，映射为中文处理建议：

- 同时识别公共域名的 AllocationQuota.FreeTierOnly 和专属域名的 insufficient_quota + 免费额度消息。
- 区分 Key 的模型访问限制、模型／工作空间授权、未开通及账户欠费。
- 保留 HTTP_403 等现有错误分类，整页翻译仍及时暂停，不会逐片段回退或自动重试。
- 不将服务原始响应、网页输入或认证内容直接回显；超大、空白、非 JSON 错误仍保留 HTTP 状态。
- 状态、错误码和请求编号通过实际后台消息传到连接界面，并适配窄屏换行。

## 验证与凭据清理

6 项新增单元与 6 项浏览器专项，加上原有回归及最终 ZIP 验收。专项覆盖两种实测错误的 code／type 兼容提取、权限提示、敏感字段过滤、响应大小上限、连接失败不保存、连接成功不重复请求、窄屏及整页在最多两个在途请求后暂停。

临时 Key 仅在调试内存使用，3 次请求后已清除并重置调试会话；没有写入源文件、插件存储、安装包或诊断记录。已通知用户删除该临时 Key。后续自动回归只使用本机固定响应和假凭据。
