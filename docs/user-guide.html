GET STARTED / 安装与使用

点译 · 安装与使用指南

Chrome / Edge 桌面版 · v0.16.0 · 2026-11-10

让遇见的词，留下来。连接自己的模型，在普通网页中划词、翻译整页或总结当前网页；短词沉淀本地词库，总结可复制导出。

1. 安装插件

本次提供可安装的本地扩展包，尚未发布浏览器商店。首次加载无需开发工具。

已有安装： 先运行新版包中的“升级点译”（工具需要 Python 3），选择原安装目录，再到扩展管理页重新加载原来的插件。旧版换目录会被登记成新插件，读不到原配置与数据；不要卸载原插件。详见升级与找回说明。

  1. 下载并解压 dianyi-chrome-edge-0.16.0.zip。也可以使用交付目录中已经解压好的 releases/dianyi-0.16.0 文件夹。
  2. Chrome 在地址栏输入 chrome://extensions；Edge 输入 edge://extensions。
  3. 打开“开发者模式”。
  4. 点击“加载已解压的扩展”，选择包含 manifest.json 的文件夹。
  5. 确认出现“点译 · 翻译与网页总结”。通过工具栏的扩展图标把点译固定，方便随时打开。

安装后会打开词句库。点击「连接我的模型」即可进入模型库。新安装没有示例词条，普通网页默认开启，黑名单初始为空。安装包面向支持 Manifest V3 的 Chrome / Edge 120 或更新版本。Chrome 和 Edge 均已使用隔离配置实际加载安装包并验收原生总结侧栏。v0.10.0 新增用于原生总结侧栏的 sidePanel 权限，浏览器可能在升级后要求确认。

2. 选厂家，填 Key，就能连接

模型库内置以下常用厂家：

厂家 你需要填写的内容 自动完成的配置
DeepSeek 自己的 DeepSeek API Key 官方接口、推荐模型、密钥鉴权与翻译参数
通义千问 阿里云百炼 API Key 北京地域的官方接口、推荐模型与鉴权
OpenAI（ChatGPT 系列） OpenAI API 平台创建的 API Key 官方接口、推荐模型与鉴权
  1. 选择你使用的厂家，粘贴 API Key。
  2. 点击“连接并保存”。首次连接可能需要在浏览器中允许访问该服务。
  3. 验证成功后，连接保存在本地模型库。在下方选择翻译默认模型；模型库里的「总结与回顾」也可直接选同一连接，无需重新填写 Key。

地址、模型名称、连接名称和超时都不需要在常用流程中手动填写。Key 输入框旁提供“获取 Key”链接，可前往对应官方控制台或申请指引。

“连接并保存”会发送一个固定测试词确认连接，可能消耗少量模型额度，不发送当前网页内容。也可选择“仅测试连接”；相同配置刚测试成功后，保存不会重复发送测试请求。

千问默认使用专用翻译模型 qwen-mt-flash，Key 由你填写，不预填或自动获取。qwen-flash、qwen-plus 仍在高级设置中可选；原来已保存的自选型号继续保留，点击“改用推荐模型”可切到 MT。专用型号已独立适配，无需自行配置接口参数。

多个 Key、默认与备用连接

在「模型库」点击「添加模型」，填写连接名称、厂家、型号与 Key，测试并保存一次。最多保存 32 个连接；翻译、总结各自最多选择 8 个，默认与备用顺序独立。新增模型默认勾选本地长期保存，也可取消改为仅本次会话；旧连接迁移保留原保存期限。

默认模型和备用从已有连接中选择，不请求模型或重复填写 Key。备用按顺序有限尝试，每个连接最多一次；取消和结果格式异常不切换，总结已输出文字不自动重跑。移出一个场景保留模型和 Key；在模型库删除则清理所有引用并列出影响。

完整使用、迁移和 Key 清理说明见模型库与词库升级保护。

本机 Codex 登录

选择「本机 Codex」，按本机连接指引安装随包助手，再检测登录、选择型号并点击「连接并保存」。无需向点译提供登录令牌。API Key 连接与 Codex 可以互为备用，翻译和总结仍分别设置。

本机助手当前支持 macOS / Linux，需要 Python 3.10+ 与 Codex CLI；Windows 上继续使用 API Key。Codex 使用其账户的权限与额度，ChatGPT 登录不等同于 API Key 按量计费。auto 使用本机默认型号，可从检测结果选择更轻量的可用型号。助手通过浏览器原生消息启动，不监听端口，不更改全局 Codex 配置。

千问的地域

默认使用中国内地（北京）的 API Key。新加坡 Key 可在“高级设置 → 服务地域”中选择国际（新加坡）。各地域的 Key 需要与地域匹配；切换地域时会清空尚未保存的 Key，不自动将原 Key 发送到其他地域。

自定义服务与本地模型

选择“自定义服务”，填写服务地址、模型名称和 API Key。无鉴权本地服务可选择“无需密钥”。支持 Chat Completions 兼容接口；远端地址要求 HTTPS，本机 localhost、127.0.0.1、::1 可使用 HTTP。

代理、企业网关、其他地域专属域名也使用自定义服务。高级设置可调整连接名称、模型与请求超时。旧版已经保存的自定义连接会继续保留，不会被自动改成某个厂家。

插件没有共享密钥或中转服务器。真实账户的模型权限、地域和额度以服务商实际配置及连接测试结果为准。

千问提示免费额度耗尽

如果连接结果显示 AllocationQuota.FreeTierOnly，或 insufficient_quota 并提示免费额度耗尽，请在百炼电脑端的“免费额度”页面搜索当前模型（如 qwen-mt-flash），检查额度与“免费额度用完即停”，同时检查账户余额。若决定继续按量付费，再自行调整计费限制；插件不会替你关闭或充值。更换服务地址无法绕过该限制。

服务地址可直接粘贴控制台提供的 Base URL，插件会补齐一次 /chat/completions。专属工作空间域名使用“自定义服务”，模型填 qwen-mt-flash；仍按专用翻译协议调用。连接失败不会保存新配置或密钥，也不会自动重试。

选择推荐翻译模型

每个厂家优先推荐一个轻量型号：DeepSeek 的 deepseek-flash、千问的 qwen-mt-flash、OpenAI 的 gpt-6-luna。主配置区直接显示型号和“推荐”标记；常规划词与网页翻译直接沿用即可。

在“高级设置 → 翻译模型”中，推荐项在前，型号后标注“推荐 · 日常翻译”。Plus／Pro 等备选注明“复杂文本备选”，可在术语密集或复杂长句时按需尝试。已选择其他型号时，也可以点击“改用推荐模型”；这只更新草稿，点击“连接并保存”后才生效。

选择“其他模型（手动填写）”可使用此厂家支持的自选型号；已有自选型号升级后原样保留。其他服务地址仍选“自定义服务”。具体推荐依据见翻译模型推荐。

2.1 选择总结模型

  1. 到「模型库」添加一个通用对话模型，或使用已有连接。
  2. 在「模型库 → 总结与回顾」选择它，Key 直接复用。翻译和总结可选相同或不同模型。
  3. 配置默认总结方式与场景提示词，保存只影响后续任务。日周月年与专题同样使用此处的模型和备用。
  4. 自动总结默认关闭；弹窗「总结当前网页」或网页右键仍可随时手动总结。需要后台处理时，在弹窗开启「自动总结与定时回顾」，同时启用后台网页总结和定时回顾，使用模型额度。

服务需支持 Chat Completions SSE 流式输出；qwen-mt-* 翻译专用型号不可选择。连接参数在模型库统一编辑；请求超时支持 5–25 秒，流式场景表示无响应超时，持续收到内容时刷新计时。

2.2 在侧栏阅读、复制与导出总结

原生侧栏展开后逐步显示结果，网页保持原来的阅读状态。侧栏只包含来源、生成状态、总结内容与制品，以及停止／重新总结、复制和导出；模型、提示词、翻译、词库仍从原插件入口使用。

  • 自动识别先识别主题，再应用对应预设，正常共 2 次模型请求；选择具体场景正常为 1 次。输出统一为简体中文，“调研分析”也仅分析当前网页，不额外联网检索。
  • 停止或中断会保留已经收到的内容，可继续阅读、复制和导出。重新总结会重新读取网页并使用模型额度；不会自动重试。单次任务最多 3 分钟，输出最多 8 万字符。
  • 向上阅读时，生成的新内容不会强制把你拉回底部；点击“有新内容 · 回到底部”可继续跟随。正文与制品可切换，代码、图形及公式保留源码路径。
  • 复制与导出支持全文 Markdown、独立无脚本 HTML；单个制品按类型提供代码文件、表格 Markdown／CSV、Mermaid 源码／SVG、LaTeX。CSV 对公式开头的单元格作安全处理；不提供可运行 HTML 制品或 Word。
  • 后台自动总结默认关闭；开启后不依赖侧栏可见性；侧栏按标签页独立开启，不会跟随到未开启的其他标签页。打开优先读取本地结果，不重复请求。
  • 长期阅读积累保存在「我的轨迹」：访问、正文、摘要、备注与版本跨重启保留，关闭标签页不删除。日／周／月／年／专题回顾见「阅读回顾」，开启自动总结后按每日 18:00 的默认时间生成，可在总结设置修改；关闭开关不影响手动生成回顾。详见阅读轨迹与周期回顾。

总结只提取当前页已加载的主要可见正文，保留其中的代码和表格；不读取表单值、编辑区、隐藏区、导航或侧边栏。不自动滚动加载后续文章。仅译文状态仍提取原文；正文超过 60,000 字符时仅纳入此前范围，并在侧栏明确提示。网页正文中的信息会发送到你配置的总结服务，请按自己的阅读内容选择使用。

可拖动浏览器侧栏分隔线调整宽度，高度跟随浏览器窗口；宽度上下界由浏览器管理。当前已验证 320／390／600px 的内容布局，物理拖动尚未完成自动化验收。完整格式、状态和隐私边界见网页总结说明。

3. 默认开启与网站黑名单

普通 HTTP／HTTPS 网页默认支持划词和本地词库标记，不需要逐站添加或开启。安装时浏览器会统一说明网站访问权限；旧版升级后如果浏览器要求确认新增权限，允许一次，再刷新网页即可。

普通网页自动保存可读取正文并使用总结模型处理，即使侧栏未开启。翻译仍需主动发起，已存词句提示直接读取本地。黑名单网站不采集、不请求、不显示侧栏；加入黑名单取消相关任务，恢复后继续之后的处理，不扫描浏览器历史。

操作 效果
直接打开普通网页 自动识别已存词句，后台保存和总结网页；选中文字可主动翻译
在插件浮窗关闭“在此网站启用点译” 将当前域名加入黑名单，立即移除标记、恢复译文并取消该网站的在途请求
在插件浮窗点击“恢复此网站” 移出黑名单，立即恢复划词与本地标记
设置 → 网站黑名单 可添加域名或粘贴完整网页地址，也可移出规则恢复使用

黑名单按域名匹配，包含该域名的子域名，以及 HTTP、HTTPS 和不同端口。例如 example.com 会同时停用 docs.example.com；其他无关网站继续默认开启。规则在刷新、重启浏览器后保留。

升级会保留模型、凭据保存方式和词库。原白名单中启用的网站改为默认开启；原来明确暂停的网站迁入黑名单，旧的临时开启记录不再生效。

3.1 浏览器鼠标右键

在正文中右键，打开“点译”子菜单：

  • 总结当前网页：使用默认总结场景，打开原生侧栏，不改变网页译文显示方式。
  • 翻译选中文字：短词句翻译并收藏；长选区按完整段落显示。仍跳过输入框、编辑器和不支持的框架内容。
  • 翻译当前页面：按块翻译，沿用最近选择的双语／仅译文模式。
  • 恢复原文：退出整页阅读，移除追加译文或还原替换文字，回到常规划词模式。
  • 在此网站启用点译：带勾表示开启，取消勾选即加入黑名单；再次勾选即可恢复。
  • 模型设置：打开自己的模型连接设置。

黑名单中的网站会禁用右键翻译入口，但仍可从右键恢复网站。整页模式下暂不翻译选中文字，先恢复原文后即可使用。浏览器内部页、扩展商店和内置 PDF 等仍受浏览器限制。

4. 第一次划词翻译

  1. 在普通网页正文中拖选一个词、短语或句子。
  2. 选区附近出现圆润的小胶囊，主按钮只显示当前目标语言，例如“中文”。
  3. 点击语言右侧的下拉箭头选择其他语言，选择会自动记住；只切换语言不会请求模型。需要语境时，打开“更多选项”勾选“附带相邻一句语境”，沿用已保存的偏好。
  4. 点击“中文”等语言名称开始翻译，等待模型返回释义。悬浮时提示“翻译为中文”，请求中可以取消。
  5. 成功结果自动保存，原文下方出现细下划线。

短选区（不超过 160 字符、位于同一内容块）翻译成功后自动保存到词库，胶囊不再显示“译成”和“并收藏”。已有对应语言释义时，点击语言名称直接查看本地结果。默认中文胶囊约 140×34px，提供下拉、更多及关闭入口。只选中、复制、选择语言或按 Esc 不会请求模型；超时、取消、密钥失效或无效结果不会生成空白词条。

超过 160 字符或跨越多个内容块时，同一个语言胶囊改为按段处理，悬浮提示“按段翻译为中文”。点击语言后翻译选区涉及的完整段落，以独立译文块对照显示，不添加下划线或括号，也不自动写入词库。一次可选最多 16000 字符；更长文章可直接使用整页翻译。语言菜单支持方向键与 Enter；第一次 Esc 收起菜单，再次 Esc 关闭胶囊，也可以直接点击 ×。

5. 悬浮释义与括号释义

整页及按段的双语译文会恢复链接、加粗、斜体、code、font、上下标和换行等常见文本标签。链接使用原地址并有下划线，可点击、用键盘打开或在右键菜单复制地址；代码保持原样，格式与标签仅在本地处理。旧的兼容页面缓存可直接恢复带格式译文，不要求重新翻译。原文仍可操作；严格校验可信事件的特殊脚本控件请使用原文入口。

释义卡片先显示译文，下方以小字保留完整原文；底部提供编辑与删除，删除后 8 秒内可撤销。较长释义自然换行，超出窗口时可在卡片内滚动查看。

音标在打开卡片时自动加载，无需再次点击。先读取已有本页结果，再查随插件内置的 125,912 条美式读音词典；词典命中无需总结模型或联网，不消耗模型额度。发音说明默认折叠，提供重音符号和部分音素的读法提示，可复制。多个读音按词典列出，需结合词性和语境判断。

本地未收录时，已配置的总结模型可结合附近语境生成英美音标与说明，并标注为模型参考；没有配置总结模型则显示本地暂无音标，保留试听，不要求先配置。模型结果按本页保存；关闭卡片继续完成已开始的查询，同一处反复悬浮复用请求，离开网页或停用点译会停止查询。本地词典当前只含美式文字音标，不包含录音。「听英音／听美音」使用浏览器语音合成和本机已有的对应语音，不调用模型、不消耗模型额度；缺少语音时会提示添加系统语音。数据来源与许可见安装包 data/pronunciation/README.md 及 LICENSES.txt。

默认使用“悬浮释义”：鼠标移到下划线，或者聚焦后按 Enter，即可查看已存释义。鼠标可以移入卡片，操作编辑与删除；Esc 可以关闭。

在浮窗或偏好设置中切换“括号释义”，正文显示为“原文（释义）”。切换不会调用模型，原文保留。再次选中文本时，插件添加的译文不会被当作原文重复翻译。

已收藏词句在其他未停用网站再次出现时，会自动标记并复用已存释义，不重复请求模型。短语优先于其中的单词；完整单词匹配避免把 art 标到 partial 内部。

同一个词在页面多处出现时，各处分别标记；计数、时钟等无关文字更新会保留现有下划线与括号，避免反复闪烁。原文增删、单词边界或词组内容真正变化时，仍会更新对应标记。

旧版本收藏的长文本保留在词库中。与完整内容块匹配时，释义改为独立块显示，避免一整段下划线和长括号；编辑、删除仍在词库中完成。

“已存释义”不代表当前语境的新翻译。同一个词可能有不同意思，可回到词库编辑。首版暂不自动判断多个义项。

5.1 整页翻译与长文阅读

  1. 点击工具栏的点译图标，选择“双语对照”或“仅译文”；此时才在当前网页右下角显示小猫。
  2. 点击「翻译整页」。如果网站已在黑名单中，按钮会显示「恢复此站并翻译」，一次点击即可恢复并开始。
  3. 页面中的标题、段落、导航文字、列表、表格和按钮标签按内容块翻译。先处理当前可见内容，短块自动合并请求；长段落分批请求，完整后再显示。
  4. 点击小猫可切换显示方式、停止、继续、重试失败块、重新翻译或恢复原文。已获取的译文在切换模式时直接复用。小猫约 24×27px（上一版的 1/3），默认隐藏，不影响划词或本地译文恢复。点击小猫展开菜单，面板右上角「×」完全关闭；再次点击工具栏点译可唤出。刷新、路由切换或网站停用后隐藏。显示时保留轻微呼吸、眨眼和摆尾；系统减少动态效果时静止，Esc 只收起菜单。
模式 阅读效果
双语对照 保留原文，在对应内容块后追加仅调整字体颜色的译文，无背景与侧线，字号默认与原文一致，可在翻译偏好选择缩小 1–4px，适应明暗页面；正文和列表保留段落对照；菜单、按钮及短表格标签在原文字区域紧凑追加，空间不足才换行，保留图标和数字徽标
仅译文 用译文更新原文本节点，保留原字号、链接、强调、图片和控件；失败块继续保留原文
恢复原文 取消待完成请求，移除追加译文并还原替换过的文字，回到常规划词模式

导航与控件不会再把整段译文追加成新的 flex/grid 子项。短标签的原文与译文并排，较长标签在文字区域内紧凑换行，单行省略样式也保留完整译文。仅译文模式保留原字号、图标、计数和事件，恢复原文会撤掉全部临时标记。

目标语言为简体中文时，已经是中文的段落、导航与常见技术名称说明保留原样，不再追加重复译文，也不重复请求整块翻译。混合中英文的页面继续翻译英文；同一段落内有独立中文、外语节点时，只追加外语部分译文。已保存的重复中文映射同样跳过。日语假名及明确的日语／韩语语言标记保留翻译处理；改为翻译到英语时，中文仍正常翻译。

小块自动合并，每批默认最多 16 块，可在“翻译偏好 → 每批翻译块数”设置 1–64。文字与片段预算随块数增长；默认 16 块合计不超过 9600 字符、192 片段，整体最多 24000 字符、768 片段。文字较多或页面结构复杂时会提前分批，同时最多两个请求；首个可见块单独请求以便尽快开始阅读。长段落仍按不超过 1800 字符的片段完整翻译。重复块及已有缓存尽量复用，切换显示方式不请求模型。片段、批量格式、响应长度或超时异常时保留原文，点击“重试失败”会逐段重试失败块。模型生成速度、网络和账户限流仍会影响实际耗时。千问 MT 使用专用纯文本翻译参数，按受保护标记核对片段；标记缺失时自动逐片段安全回退，实际请求数可能增加。

“翻译偏好 → 译文文字颜色”分别设置浅色、深色页面的颜色，支持点选调色板、打开浏览器取色器、填写六位颜色值及恢复默认，并提供本地预览。保存后应用于双语／按段译文、悬浮释义和括号释义；不重新请求模型。正在翻译时保存块数或颜色，会保留已有结果及在途请求，新批次采用新块数。

整页／按段模式期间暂停划词工具、词库下划线和括号；它们与长文阅读分开工作。整页译文进入独立的本页暂存与请求缓存，不自动变成词库中的大量长句。

页面后来加载新内容时，小猫菜单提示页面有新内容，点击“翻译新增内容”才继续发送；不自动翻译无限信息流。首次最多处理 400 个块或约 12 万字符，较大页面会显示剩余数量，点击“继续翻译”继续处理。每个段落会完整显示，不在半段处强行截断。

网页在翻译期间改写的内容优先保留，旧结果不会覆盖新文本。页面路由变化、网站停用或翻译设置变化会退出原阅读任务；可在新页面重新翻译。模型返回的片段不完整时保留原段落，可单独重试失败块。

刷新恢复与重新翻译

  • 翻译成功后，在本机暂存该页面的段落与片段映射。刷新后核对原文与结构，只恢复仍匹配的内容，不自动请求模型；即使本次浏览器会话的 Key 已清除，仍能加载本地译文。
  • 完整网址（包括查询参数与锚点）、目标语言、风格、提示词和模型配置分别对应暂存。原文或链接变化的段落保留原文，未变段落仍可恢复；不会把旧译文顺延到别处。
  • 「重新翻译」重新请求模型，跳过本页和片段的旧结果，并更新本页暂存。它会使用模型额度；「加载本地译文」只读本机结果。
  • 「恢复原文」后刷新也保持原文，点击小猫中的「加载本地译文」可重新显示。双语／仅译文的选择也随本页暂存保留。
  • 暂存约 7 天，最多 50 页、合计约 20 MiB、单页约 3 MiB／1000 个块。超过容量时淘汰较旧内容；可以在「本地数据 → 页面译文暂存」清除，不影响词库或模型配置。
  • 页面暂存只在本浏览器保留，不随词库导出。行内代码用占位符映射，页面地址查询参数和链接目标只参与摘要，不明文写入暂存。

6. 管理词句库

通过浮窗“打开我的词句库”进入。

  • 搜索原文或中文释义，按单词、短语、句子筛选。
  • 按最近收藏或字母排序，每页最多 50 条。
  • 点击原文查看来源、收藏时间和可选语境，修改并保存释义。
  • 悬浮卡片或词库中删除，所有已启用网页的对应标记同步移除。
  • 单条删除直接生效；批量删除和清空会确认数量与影响；8 秒内可撤销。
  • 导出 JSON 保存词句和必要来源信息，不包含 API Key、鉴权请求头或地址查询参数。

词库在原本地数据库持续保存，并自动更新浏览器本地副本。支持 JSON 导出与合并恢复，已有释义保留；没有云同步、账号或复习打卡。

7. 调整语言和翻译风格

目标语言默认简体中文，可选 English、日本語、한국어、Français、Deutsch、Español。切换后，网页只匹配该目标语言对应的词条；原有词条不会被删除或覆盖。

风格 表达方向
常规 自然、简洁，优先常见表达
专业 术语准确，解释概念与边界
幽默 先准确释义，再添轻松的记忆点
自定义 自己设置语气、领域和解释深度，最多 4000 字符

自定义提示词支持 {{text}}、{{targetLanguage}}、{{context}}。实际原文与可选语境以独立资料传给模型，不作为需要执行的指令。准确、忠实和纯文本输出约束始终保留。

语言、风格和模型变更只用于后续翻译；已经保存的释义保持原样。正在阅读的整页译文会还原，避免混合不同设置的结果。整页模式始终要求完整翻译，即使风格提示词要求简短解释，也不概括或删减原文。

8. 密钥与隐私

  • 新增模型默认勾选本地长期保存，可取消改为当前浏览器会话；旧连接迁移不改变期限。
  • 可明确勾选“在此浏览器长期记住密钥”。这是浏览器本地存储，不是安全密码保险箱，不会冒充加密保险库。
  • 网页内容脚本无法读取扩展配置或密钥。模型请求由扩展后台发送，密钥不进入网页，也不出现在词库导出中。
  • 不上传词库到点译服务器，不加载远端脚本，不使用访问分析或追踪服务。
  • 划词时，模型只接收确认翻译的选区和你选择附带的有限语境；按段时发送涉及的完整段落；整页时分块发送当前已加载的可读文字。
  • 翻译的整页请求跳过输入值、可编辑内容、代码块、隐藏内容和不翻译区域；总结保留主要正文中的代码与表格，但跳过输入值、编辑区、隐藏、导航和侧边。仅译文状态总结读取原文。Cookie 和页面 URL 不随正文请求发送；正文中可见的信息会发送到所选服务。
  • 模型库统一保存连接与 Key，各场景独立选择默认与备用；阅读轨迹、正文快照、摘要与回顾长期保存在本地，可分批导出 ZIP、Markdown、HTML、JSON／JSONL、CSV，不含 Key。卸载前请先备份，阅读轨迹没有云同步或导入恢复；词库可通过 JSON 合并恢复。

“数据与隐私”页面可清除模型库全部 Key，所有引用场景都会受影响；连接配置和本地词库保留。更换目录、浏览器或卸载前导出 JSON，可在词库「恢复词库」中恢复。

10. 升级与备份

  1. 卸载、清除扩展数据或更换设备前，先导出词库备份。
  2. 已有旧版运行包内“升级点译”，选择原安装文件夹；工具保留原身份字段，不能直接用新清单覆盖旧身份。
  3. 在浏览器扩展管理页点击重新加载；若提示新增网站访问权限，允许一次，再刷新已打开的网页。
  4. 不通过卸载再安装的方式升级；新文件就位后必须重新加载扩展。v0.14.2 起新安装使用固定插件标识，换目录加载也保持身份；旧安装继续用升级工具。
  5. 词库页提供「导出词库」「恢复词库」，数据与隐私页显示自动副本；更换安装目录前请先导出，恢复时保留已有释义。详见模型库与升级保护。
