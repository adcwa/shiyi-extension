点译 · 宣传文案与素材说明

2026 年 11 月 3 日 · 面向按需阅读外语网页、希望使用自有模型的桌面浏览器用户。

核心表达

翻译，按需付费。再遇见，就提醒。

用自己的模型 Key，按服务商的用量规则付费。查过的词句留在本地，下次阅读时，释义会在原文里再次出现。

主行动统一为「开始使用点译」：安装后的介绍页进入原模型连接页；独立介绍页进入安装步骤。

为什么做点译

我经常在外语网页里查词，也常在下一篇文章里遇到同一个词。我想自己选择模型，让费用跟着实际用量走，也让查过的词句在阅读中主动提醒我。

需要时，选择适合这次阅读的模型发起翻译；翻译成功后，把短词句留在本地，让认真查过的内容不只停留在一次查询里。

于是有了点译。需要时翻译，查过就留下。换一篇文章再遇到，正文里有一条熟悉的下划线，也有之前存下的释义。

这就是点译的出发点：自带模型、按实际用量使用服务，以及查过的词句跨网页主动提醒。

可直接复用的短文案

点译是一个使用自有模型的浏览器阅读插件。我做它，是想把两件事放在一起：按服务商的实际用量规则付费，以及在阅读中再次看见查过的词句。划词翻译成功后，短词句会留在本地词库；换一篇文章，再遇见同一个词，正文里的下划线就能带你回到之前的释义。也可以按需翻译整页，或在独立侧栏总结当前网页。

自己的模型，自己的词句库。把一次查词，变成下一次的眼熟。

四个阅读收益

  • 模型和用量，自己选。 连接自己的服务，用选定型号的计费规则结算，主动发起需要的任务。
  • 换一页，释义还在。 已存词句在当前目标语言下跨网页复用，不因自动提示而再次请求模型。
  • 提醒，留在原文里。 细下划线、悬浮释义或括号显示，让提醒发生在实际阅读中。
  • 长文章，也有读法。 整页双语、仅译文与独立侧栏总结，分别服务连贯阅读和提炼重点。

文案边界

「按需付费」指所选模型服务的用量与账户计费规则，不表示点译拥有自己的按量收费系统，也不承诺全部型号永久免费。没有访问账单或计算节省金额，不使用虚构价格、节省比例、客户姓名、评价或合作标志。

「主动提醒」指当前目标语言词库命中时，在正文标出已存词句；不表示定时通知、间隔复习或模型重新判定义项。提醒复用本地释义，旧释义仍应结合新语境核对。

介绍页交付

  • 管理界面入口：options.html#about，名称「产品介绍」。翻译、总结、词库与设置原入口保持可用。
  • 独立页面：../src/intro.html；本地预览 http://127.0.0.1:8428/。
  • 章节：首屏实拍、设计初衷、四个收益、逐词标语、三步使用、两页阅读案例、八个 FAQ、开始使用、隐私和使用说明。
  • 管理内页面不索引。未虚构官网域名、商店下载地址或已发布链接；本地预览提供真实安装包下载与品牌 404。
  • 字体为本地 Geist，图标为本地 Phosphor。保留随包许可；中文使用浏览器的字形回退。没有远程字体、追踪 Cookie、统计脚本或订阅表单。

默认、备用与本机登录的说明

翻译与总结各自支持最多 8 个连接。相同厂家不同 Key 各自保存，可指定默认并调整备用顺序；发生受控故障时依次尝试，总结已输出后不自动切换重跑。备用服务可能处理相同资料并使用相应额度。

本机 Codex 通过随包本机助手复用 CLI 登录，浏览器不导入或保存登录令牌。其账户权限与额度规则独立，ChatGPT 登录不等同于普通 API 按量计费。当前本机助手支持 macOS / Linux。相关说明和恢复入口在本机连接指引。
