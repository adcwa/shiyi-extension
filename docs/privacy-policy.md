# 点译隐私政策

更新日期：2026 年 11 月 10 日 · 适用于点译 v0.16.0

点译帮助用户阅读网页，提供划词和整页翻译、读音、语境补充、网页总结与阅读回顾。点译不设账号，不提供词库云同步、广告或行为分析服务。模型服务使用用户自行选择的连接与凭据。

## 本地保存

词句、释义、来源、翻译偏好、停用网站规则、模型连接与 API Key 保存在本机浏览器。词库另有本地自动副本。Key 可以长期保存或仅保留本次浏览器会话，不包含在词库或阅读知识导出中；浏览器本地存储不是加密密码保险箱。

允许页面的标题、网址和访问时间等元信息在本机登记。自动总结默认关闭：关闭时不自动提取网页正文或请求总结模型。用户可以随时手动总结。开启后，符合权限和黑名单规则的页面可保存可读正文、摘要、备注与来源关系，供后续检索及日、周、月、年和专题回顾；默认每日 18:00，可修改时间。不会扫描浏览器既有历史。

词库、轨迹、快照、摘要和回顾保存到用户主动清理；页面译文与语境补充缓存有容量限制。卸载扩展或清除浏览器数据可能删除这些资料，请先导出备份。原位升级保持原插件身份与本地存储，升级工具只更换程序文件，不读取 Key 或移动浏览器数据库。

## 发送给用户配置的模型服务

点译没有共享模型 Key 或中转服务器。模型请求直达用户配置的 HTTPS 服务或本机回环服务，使用该服务的账户权限和额度；已启用的备用连接可能在默认服务失败后处理同一任务。

- 划词翻译发送所选文本及用户选择附带的附近语境；整页翻译发送当前页面的可读内容块。
- 已配置总结模型时，划词翻译可并行请求语境补充；“展开更多”同样使用该模型，处理词句、已有释义及附近语境。补充结果按本页缓存并复用。
- 手动总结或开启自动总结后，网页总结发送主要可见正文、标题、少量直接相关阅读摘要及用户备注；周期和专题回顾使用本地已存摘要、备注与来源关系。
- 连接测试发送固定短词来验证服务，不发送当前网页正文。

表单输入值、编辑区内容、Cookie 与浏览器登录凭据不进入这些请求。模型服务如何保存和使用收到的资料，由其服务政策及用户的账户协议决定。

## 本地音标和系统试听

打开词句释义卡片时自动加载读音。已有本页结果和内置美式读音词典优先在本机读取；词典查询不联网，不向词典作者或网站发送原词、网址或语境。内置词典只包含文字音标，没有录音，多个读音需结合词性与语境判断。

本地未收录且用户已配置总结模型时，词句与附近语境会发送给该模型生成音标、重音及发音说明，结果缓存到本地。没有总结模型时，仅提示本地未收录并保留试听，不发起读音模型请求。模型生成的内容标注为读音参考。

英式、美式试听通过浏览器调用系统已有的对应本地语音，不调用模型或远程语音服务。缺少语音包时提示用户在系统中添加。

## 本机 Codex

这是可选连接，需要用户自行安装随包助手。点译通过浏览器原生消息调用 Codex CLI，使用现有登录；不导入 `auth.json` 或在浏览器保存 OAuth 令牌。任务受本机 Codex 的账户、组织策略和服务配置约束。点译启动的模型任务不提供命令执行或文件工具。

## 网站停用、查看与导出

黑名单网站不采集、不发起新任务、不显示总结侧栏，在途任务会取消。历史资料及引用该来源的上下文不进入新的汇总或导出。浏览器本身的网站访问权限继续生效。

可在扩展管理页查看、编辑、删除词句，查看和导出阅读轨迹及回顾，并清理模型 Key 或本地资料。导出在本地完成。点译不会出售用户数据，也不为广告、信用评估或与网页阅读无关的目的传输数据。

## 介绍页与联系

介绍页不加载分析脚本、追踪 Cookie、远程字体或在线表单。扩展代码、词典及制品渲染器随安装包提供；模型响应只作为内容数据处理。外部链接遵循目标网站政策。

隐私问题可通过[项目支持页面](https://github.com/adcwa/shiyi-extension/issues)联系。提交公开问题时请勿附带 API Key、敏感网页或个人资料。
