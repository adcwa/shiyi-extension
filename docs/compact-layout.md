# 点译 v0.6.1 · 小猫入口与双语界面留白优化

2026-11-03

## 目标

网页平时保持安静；需要时从工具栏唤出小猫。正文适合按段对照，导航与控件需要保持紧凑，译文应跟随文字，避免把图标、标签和数字计数撑散。

## 小猫方案

- 图形从 72×80px 缩至 24×26.67px，约为原尺寸的 1/3；点击区域保留为 32×36px，菜单文字保持可读。
- 新网页、刷新、路由切换和本地译文恢复时隐藏。用户打开工具栏点译后，才在当前文档显示小猫，显示操作不请求模型。
- 点击小猫展开功能；面板右上角「×」完全关闭，Esc 仅收起菜单。进度更新、配置广播和插件浮窗轮询不会重新唤出已关闭的小猫。
- 保留轻微呼吸、眨眼与摆尾；系统减少动态效果时静止。取消常驻「点译／已完成」文字牌，翻译中只显示小点，完整进度在菜单中查看。

## 留白根因与验证

以带图标、文字、计数的菜单项构建真实扩展复现，逐步缩小至一个 grid 菜单项；使用隔离 Chromium 和本机固定响应服务，不包含账号数据或真实模型 Key。

| 检查 | v0.6.0 实测 | 判断 |
| --- | --- | --- |
| 一项菜单，翻译前／后 | 36px → 134.39px | 译文作为新 grid 项进入 16px 图标列，逐字换行 |
| 只去掉译文外边距 | 132px | 间距并非主要原因 |
| 只把译文移入文字区域 | 64.58px | 插入位置是主要原因，仍需紧凑布局 |
| 该菜单返回的整段译文 | 合并请求1 | 数字计数混入了重复译文 |

## 实施方案

| 内容 | 显示方式 |
| --- | --- |
| 正文、长段落 | 保持段落后的独立译文块，颜色区分，无底色／侧线，字号默认不缩小，可配置缩小 1–4px |
| 导航、按钮、短表格标签 | 使用已对齐的片段译文，追加到对应文字区域，短标签并排 |
| 长菜单标签 | 译文作为整体换到紧凑次行，不占用图标／计数列，无上下外边距 |
| 单行省略的标签 | 先尝试并排；溢出时只把译文改为文字区域内的一行，不改宿主样式 |
| 纯数字徽标和图标 | 保留原位和原值，不追加重复释义；仅译文模式同样保留纯数字 |
| 仅译文 | 继续更新原文本节点，保留原字号、控件元素和事件 |

匿名文本位于 flex/grid 容器时，仅用临时透明标签把原文节点与译文组合为一个布局项；图标、计数和箭头保持原来的布局项。一个阅读记录可拥有多个译文片段，模式切换与恢复统一清理。原节点身份保留，移除临时包裹后原 HTML 精确还原。

本地映射把临时包裹视为透明，原文结构签名与已有缓存兼容，不需要因为排版更新重新请求模型。

## 验证结果

| 指标 | 原页面 | v0.6.0 | v0.6.1 |
| --- | --- | --- | --- |
| 8 项侧栏总高 | 345px | 543.56px | 363px |
| 长菜单项 | 36px | 134.39px | 54px |
| 其余 7 项菜单 | 每项 36px | 部分 63–81px | 每项 36px |
| 数字徽标列与内容 | 原始值 | 可能重复进入译文 | 原列、原值 |
| 刷新恢复新增模型请求 | — | — | 0 |

21 项专项覆盖小猫默认隐藏、工具栏唤出、1/3 尺寸、关闭与防止自动唤出、标签／数字对齐、匿名文本、多片段按钮、单行省略、原 HTML 恢复、文本节点与按钮事件保留、缓存恢复及无未捕获错误。实测是代表性布局验证，不代表所有网站都具有完全相同的结构。
