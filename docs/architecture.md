# 点译 v0.13.0 · 实现说明

2026-11-04

## 默认开启与黑名单

Manifest V3 声明 HTTP／HTTPS 网站访问和一组静态主文档内容脚本，普通网页默认启用。浏览器内部页、扩展商店、PDF、iframe 与 Shadow DOM 内容仍不处理。初始黑名单为空，翻译由明确操作触发；总结按已授权需求默认后台采集并处理符合条件的网页，不依赖侧栏可见性。

lib/site-policy.js 将域名或完整网址规范化为域名，按同域名及子域名匹配，跨协议和端口。合并重复和被父域覆盖的规则，避免恢复网站时还残留另一条覆盖规则。BLACKLIST_SET 仅可信 UI 可调用；原生菜单从浏览器事件进入同一操作。

加入黑名单先取消匹配域名的在途请求，再保存配置并广播，所有相关标签页撤去标记和译文。恢复规则会向已有页面注入或刷新，使功能立即恢复。每个翻译请求及响应落库前均重新检查真实 sender 的 tabId、documentId、frameId、生命周期与黑名单，不允许内容脚本指定任意端点或绕过停用。

## 升级迁移

配置改为 version: 2、sitePolicy: blacklist、blacklist: 域名数组。原 sites 中明确 enabled: false 的网站迁入黑名单；原开启网站改用默认启用。移除旧 sites 和过期的 temporary 开启映射，不改动原有模型、偏好或凭据记录，不会清空词库。v0.6.0 将同一个 shiyi-vocabulary 数据库从版本 1 升到版本 2，仅增加 pages 存储与索引，保留 entries、cache、meta、trash 和既有配置。名称、消息协议与安装路径中的旧内部标识保留以兼容已有用户。

启动时注销旧版 shiyi- 前缀的动态白名单脚本，改用清单中的唯一静态注入列表，避免升级后重复注入。已有页面在安装／更新时尝试刷新内容脚本；用户重新加载扩展后刷新网页即可使用新脚本。Chrome 对新增网站权限的提示由浏览器处理，不自动代替用户接受。

## 原生右键菜单

contextMenus 权限创建“点译”子菜单：总结当前网页、选区翻译、整页翻译、恢复原文、网站启用复选项、模型设置。入口限制普通 HTTP(S) 网页，随着活动标签、网站状态与阅读状态更新。使用 onClicked 监听器，兼容后台 Service Worker，不依赖仅其他浏览器提供的菜单显示事件。

短词右键不直接拿任意字符串请求模型。内容脚本在真实 contextmenu 事件保存有效正文选区及范围，点击菜单后与浏览器提供的选区匹配，最多 16000 字符；输入框、编辑器、子框架或陈旧选区不发送。长选区进入按段阅读，短选区沿用释义／收藏链路。黑名单状态在入口和后台再检查。网页中的注入控件只接受真实用户操作，宿主脚本的合成点击不能请求模型、修改词库或开启语境发送。

原生网站复选项与浮窗使用同一持久黑名单，恢复立即生效。浏览器访问权限被撤销时，不把开启操作误当作添加黑名单；浮窗会说明需要浏览器允许网站访问。

## 模型连接与翻译请求

DeepSeek、千问和 OpenAI 预设提供固定官方端点、推荐型号与鉴权。千问默认 qwen-mt-flash，保留 qwen-flash／plus 为可选项；Key 不预填，获取入口位于输入框旁。模型标识独立于“推荐”标签，未知旧型号保留；手动型号和自定义服务均可使用。推荐依据见[模型推荐](provider-defaults.md)。

只在用户点击连接／翻译后请求。密钥按端点与鉴权身份匹配，切换厂家或地域清空尚未保存的 Key。默认 chrome.storage.session 保存；明确勾选才写 chrome.storage.local，均限制 TRUSTED_CONTEXTS，内容脚本不可读取，不进入词库导出。

请求固定发往用户保存的端点，关闭 Cookie、Referer 和重定向；不发送页面 URL。响应最多 128 KiB，单条释义最多 2000 字符。网络、超时、取消、401／403／429、拒绝及结构异常分别处理，不透传上游敏感响应。删除、编辑、设置变化和网站停用均会取消相关在途请求；词库修订号防止迟到写回。

## 原生总结侧栏与入口

v0.12.1 保留 `sidePanel` 权限，移除清单的全局 `side_panel.default_path`，启动时关闭旧全局回退。`summary-panel.js` 为每个有权限、未被黑名单禁用的普通网页设置 `summary.html?tabId=ID`。工具栏和原生右键均在用户手势中同步调用 `sidePanel.open({tabId})`，不再用 `windowId` 打开整个窗口；后续任务由后台持有，不依赖弹窗继续存活。注册入口只提供可用性，不会打开侧栏或调用模型。

全局与按标签页路径的选择遵循 [Chrome Side Panel API](https://developer.chrome.com/docs/extensions/reference/api/sidePanel) 的上下文语义。实测 Chrome 禁用后台已打开页的侧栏会关闭前台其他页的同扩展侧栏，因此先立即取消被禁用页的任务；当前台其他页仍在展示侧栏时，把后台页的原生禁用延后到该页激活时处理。请求始终重新检查黑名单，不因这项浏览器界面处理而允许禁用网站调用模型。

侧栏只显示来源、状态、总结正文与制品，以及停止、重新总结、复制、导出。模型表单、提示词、翻译和词库不进入侧栏；设置由原 `options.html` 的 `#summary` 管理，翻译 `#model` 保留。侧栏通过受信任扩展端口接收公开任务快照，不接收 Key，不直接访问模型端点。高度、关闭按钮和可拖动分隔线由浏览器提供，宽度上下界归浏览器管理；内容已验证 320／390／600px，物理拖动尚未完成自动化验收。

## 独立总结连接、正文与流式任务

配置的 `summaryProfile`／`summaryPrefs` 与原 `profile`／`prefs` 分离；`summaryCredential` 与 `credential` 是独立的 session／local 记录，分别按端点及鉴权身份匹配，即使同地址也不读取另一用途的 Key。两套凭据均默认会话保存，分别明确 `rememberKey` 才写 local，均限制可信扩展上下文。总结默认为千问 `qwen-flash`，拒绝 `qwen-mt-*`；翻译默认及 MT 协议不变。保存总结配置或清除 Key 会停止相关总结，不修改翻译连接。连接测试用固定短文检查真实流式能力，不发送网页资料。

`summary-extract.js` 通过 `chrome.scripting.executeScript` 在顶层隔离环境优先读取 article，再读 main／主区域，最后回退正文。排除表单值、编辑区、隐藏、导航、侧边及插件节点，保留主要正文代码与表格；不进入 iframe、Shadow DOM、PDF、Canvas。仅译文模式通过原文访问器恢复来源文字。最多 60,000 字符及有界节点遍历，截取标志进入公开状态；执行前后核对真实标签页 URL，防止把切换前页面当作当前来源。

`summary-panel.js` 保持每标签页独立的原生侧栏路径和显示状态；端口只能绑定自身 URL 中的 tabId。v0.13.0 的 `summary-manager.js` 适配到持久知识执行器，网页导航与可读通知触发后台采集，侧栏仅订阅当前页状态。打开、绑定、刷新和原生事件复用同一任务或结果，不以可见性决定是否总结。

每次执行重新检查来源、上下文、黑名单、网站及模型权限；网页不能自选模型端点。禁用按域名取消，其他站点仍可处理；移出黑名单恢复后续采集而不强行打开侧栏。任务由后台持有，已保存快照不依赖来源标签页存活，结果长期保留。后台重启标记未完成的进行中任务为中断，保留部分文本；任务最长 3 分钟、输出最多 8 万字符。

自动场景先以正文前 10,000 字符以内摘录请求一次非流式分类，再按选定场景请求 SSE 总结，正常共 2 次；手动场景只发 1 次。分类类型无效或分类内容不完整时回退通用总结并说明。所有总结使用简体中文，只分析提供资料，网页命令作为不可信内容，不额外联网调研。错误不自动重试，主动重新总结才新建任务。

`summary-model.js` 使用增量 UTF-8 和 SSE 解码，处理跨网络块事件及结束标志；只采集内容增量，区分断流、长度截断、拒绝、HTTP 服务错误、空结果和无效格式。以收到响应数据刷新 `timeoutSeconds` 空闲计时，该配置是无响应秒数，不是任务总时长。取消、断线和超限保留已经发布的文本，任务身份检查阻止迟到增量。请求不发送 Cookie／Referer、不允许重定向；跨增量密钥脱敏保护面板及导出。模型只收到正文和提示词，不附加页面 URL。

## 总结渲染、制品与构建

总结使用本地打包运行时 markdown-it 15.0.3、Mermaid 12.2.0 和 KaTeX 0.19.1，不加载 CDN 或远程字体。`npm ci` 后运行 `npm run build:renderers`，由 esbuild 0.28.2 与锁定依赖生成 `src/vendor/summary-renderers.js` 及许可清单；Mermaid 依赖的动态 CSV 编译替换为静态映射，不使用动态执行，适应 MV3 严格 CSP。

Markdown 原始 HTML 关闭，链接使用受控协议；Mermaid 使用 strict、禁用 HTML 标签并清理 SVG，KaTeX 关闭 trust，输出 MathML。源码围栏未完成时先呈现原始文本，完整后再作为代码／图形／公式制品。总结正文与制品的阅读位置分别保存，流式渲染复用未变化节点，向上阅读时保留位置，不强制拉回底部。

全文复制为 Markdown，导出 `.md` 或自包含无脚本 `.html`；来源地址去除查询参数和锚点，部分／截取结果带状态。单个制品导出代码、表格 Markdown／CSV、Mermaid／SVG 或 LaTeX。CSV 对公式触发字符开头的值添加保护。模型 HTML 按文本处理，HTML 代码保存为 `.txt`，不提供可运行 HTML 制品、交互图表环境或 Word 文件。

## 千问 MT 与中文去重

lib/qwen-mt.js 单独处理 qwen-mt-* 模型的单 user 消息与 translation_options，接收纯文本响应；普通 Chat Completions 继续使用原有结构化协议。自定义地址使用相同 MT 型号时同样适配。原文按随机标记分帧，以术语参数保护标记，完整核对每个 ID、边界与长度；正常响应合并多个片段，边界损坏才按片段回退。全局两并发、去重、代码占位符、缓存、取消、超时和 HTTP 鉴权／限流保护均保留。网络失败与超时立即中断，不转成逐片段请求。

ShiyiText.isTargetLanguage 针对目标中文识别中文及常见技术标识，参考节点语言标记，保守处理明确日语／韩语和外语文本。收集时跳过已是中文的内容；渲染时再次检查，从而不加载旧缓存里的重复中文。混合段落按原节点对齐，中文节点不追加、不改写，仅保留外语译文。与原文等价的模型结果也不重复显示。切换目标语言为英语时仍翻译中文；中文显式划词释义功能不受整页过滤影响。

## 短词与按块阅读

v0.9.0 的双语普通段落由 ShiyiInline.capture 在本地保存标签嵌套、源节点、换行与链接绑定；模型仍只接收已有文本片段 ID。渲染根据 record.values 重建受控标签和 Text 节点，保留 a、code、b／strong、font、上下标等 35 种常见文本标签。普通链接操作转交有效的原节点，组合键与中键使用原生 href；已处在原链接中的紧凑译文不创建嵌套 a。原 code／kbd／samp／var／tt 内容保护不发送，URL 形式链接文案保持原样。仅译文仍修改原 Text.data。

映射校验来源节点、层级、换行及链接属性；链接变化撤去旧译文，字体属性变化、主题和视口变化只原位更新格式。标签属性与树不写入模型协议或页面暂存，已有兼容 values 结合当前 DOM 直接重建，无需重译。白名单创建元素、不解析模型 HTML、不复制任意 on*、ID、原始 CSS 或资源控件。双语颜色按配置统一、字号按各源节点减 2px。实现边界、isTrusted 限制及升级验证见[通用行内标签映射](inline-structure.md)。

v0.8.0 的划词入口为约 140×34px 胶囊，主按钮仅显示目标语言简称；辅助说明通过 title／aria-label 告知翻译或查看本地释义。下拉列出七种目标语言，更多保留语境偏好，× 和 Esc 支持关闭，菜单支持键盘和视口边界定位。长选区沿用同一语言胶囊并进入按段阅读。

SET_TARGET_LANGUAGE 仅接收有效普通网页的当前文档调用，通过 cleanPrefs 验证枚举，在串行配置更新中只修改 targetLanguage；实际改变时取消旧语言请求并广播。切换语言不调用模型。刷新活跃选区工具时原位更新胶囊并保留选区，优先完成显式选区操作，避免切换语言时自动载入整页缓存；模型请求仍由真实用户点击触发。页面脚本模拟点击／事件不能设置语言、发送语境或请求模型。

短词和同块内不超过 160 字符的选区沿用 Trie、本地释义、下划线和可选括号。跨强调／链接保留原节点；移除装饰时仅合并自身创建的分片，不全局 normalize。长词库记录完整命中内容块时单独显示译文。

v0.7.1 动态扫描和词库同步统一走逐处增量对齐。旧版「整组一致则跳过，否则清空整个根节点再分帧重建」在真实命中变化及全局刷新时仍会销毁未变化标记。现在以真实 Text 节点、片段范围、词库 ID 定位实际出现位置，复用有效标记与括号节点，只拆除失效片段、插入新增片段；释义和颜色就地更新。相同 ID 的多个出现位置独立处理，注入释义在所有扫描入口透明跳过。计划和修改在同一次回调内完成，扫描按 200 节点／8ms 分批，但从不预先清空页面。匹配片段按有序偏移推进。

源文本分片通过 WeakMap 标注所属原始文本序列。局部删除可以发生在序列中间，后续仅合并插件创建且属于同一序列的相邻文本节点，不依赖已经失效的成对 before／after 引用，也不全局 normalize。关闭、停用和进入整页阅读时仍精确还原原 HTML 与页面原 Text 节点。复现和前后测量见[重复词闪烁修复](annotation-stability.md)。

长选区与整页阅读期间暂停词库装饰。长段落按最多 1800 字符、60 个片段拆分，优先句子边界，不拆断 Unicode 字符；每段全部片段完成后显示。先按当前视口选择处理预算，并在批次间重新排序，首个可见块单发，后续默认最多 16 块合并为一次请求，可配置 1–64；保留两个并发。字符／片段预算由 batchLimits 随块数增长，默认 9600 字符／192 片段，上限 24000 字符／768 片段。请求只要求块与片段 id 对应的译文，不重复生成整段全文。

收集时给每个内容记录分配稳定且唯一的块 ID，片段 ID 在块内对应原 Text 节点。响应使用块 ID 与片段 ID 两级映射，不依赖返回数组顺序；双语与仅译文共用校验后的映射。重复或缺失结果只使对应块失败，不将内容顺延到相邻块。每次落页仍检查任务代次、节点身份和源文本，网页后来更新的内容优先。

TRANSLATE_BLOCK 与 TRANSLATE_BLOCKS 共用可信来源、文档身份、取消与模型权限检查。每块仍使用原 block-v1 缓存身份；合并前读取缓存，只发送缺失块，并按缓存身份去重。响应按块隔离验证，成功块独立缓存与显示，格式错误的块保留原文；用户重试时降为单块，不重复请求成功块。401／403／429 暂停全队列，无自动无限重试。

双语按内容块追加，译文仅使用独立文字颜色，不加背景、边框或侧线；字号为来源的计算字号减 2px，行高同比缩放，监听视口尺寸变化。按所在区域背景选浅／深色配对，并监听系统主题与根节点主题变化，不修改原文元素的样式。translationColorLight／translationColorDark 是经六位十六进制校验的本地偏好，用 CSS 自定义属性应用到双语块、悬浮卡片与括号释义。设置页提供原生取色器、色板、颜色值与预览，提示不易分辨的配色。列表、表格和 flex／grid 项内部追加，避免改变布局关系。仅译文修改原 Text.data，保持原字号、链接、图片、控件和事件。恢复只还原仍等于插件所写译文的节点，网站更新优先；页面路由变化撤销旧任务。完整方案见[按块阅读](block-reading.md)。

块数与颜色不参与翻译语义签名或缓存身份。保存这两类偏好不会取消在途请求或退出阅读；现有译文就地更新颜色，之后的批次读取新块数。后台输入保护采用全局硬上限，允许调整块数前已经发出的合法大批次完成。语言、风格、提示词等翻译内容变化仍取消旧任务。

翻译页面任务由内容脚本维护，后台处理独立短请求；总结任务由后台单独持有并使用有界流式生命周期。停止／继续保留已完成结果，显示切换复用结果，失败可重试。新内容提示后由用户主动翻译；首次 400 块或约 12 万字符后需要继续。页面结果进入 block-v1 请求缓存及独立页面映射暂存，不污染词库。

## 页面暂存与恢复

页面身份为完整 URL 与翻译语义签名的 SHA-256 摘要，后台同时核对请求地址与当前真实标签页地址，处理 SPA 的查询参数与锚点切换。存储的来源说明移除查询参数与锚点。修改颜色、每批块数不改变语义身份；模型、语言或提示词变化独立保存。

每个内容块保存定位路径、完整结构签名和对齐后的片段译文。签名包含原文、片段父路径、语义标签、角色与链接摘要；行内代码用占位符代替。恢复先按路径与完整签名严格匹配，唯一结构允许移动，重复相同文本不猜测对应。所有签名仍逐字核对，不仅依赖短摘要。重建时保留当前真实代码与原文本节点。

翻译块在落页前尝试提交本地检查点；刷新只载入匹配块，不运行请求队列。保存显示模式和启停状态，用户恢复原文后禁止自动恢复；手动加载不访问模型。「重新翻译」打开新修订并清空本页旧映射，同时绕过 block-v1 缓存。新任务始终旋转 UUID 修订号，旧任务迟到保存被拒绝；取消后的结果不能再落页。部分重新翻译保留 fresh 标记，后续继续仍跳过旧请求缓存，直至全部完成。

页面保留约 7 天、最多 50 页、20 MiB，总计有索引与容量统计；单页 3 MiB／1000 块。按更新时间淘汰较旧映射，超限或存储失败不阻止当前译文显示。提供独立清除入口，不改词库、模型与密钥。

小猫默认隐藏，仅打开工具栏 popup 时通过可信 show-companion 操作显示在当前文档；24×26.67px，点击展开翻译控件，面板右上角可完全关闭。后台广播、进度更新和本地恢复不会自动唤出，路由切换或刷新后再次隐藏；呼吸、眨眼、摆尾使用 transform 动画，支持 prefers-reduced-motion、键盘与 Esc。功能按钮沿用真实用户事件校验，宿主网页合成点击不能请求模型。

## 紧凑界面排版

侧栏复现发现，整块译文被作为新的 flex/grid 项追加到链接或按钮，网格可能把它分配到 16px 的图标列；数字徽标同时混入整段译文。移除外边距不能解决窄列逐字换行。

短控件（不超过 160 字符）与导航采用片段对齐值，就地追加到对应文字区域。独立数字、标点徽标和代码不重复追加；仅译文同样保持纯数字原值。较短译文作为 inline-block 跟随原文，长译文在标签内换行，nowrap／ellipsis 标签溢出时只让译文另起无外边距的一行，不改变宿主控件样式。正文继续按内容块追加，无底色与侧线。

匿名文本节点位于 flex/grid 根容器时，仅用临时透明 span 包裹原节点，使原文和译文共享一个布局项；图标和计数仍在原列。原节点、元素及事件保留。一个阅读记录可以拥有多个译文片段；模式切换、主题与字号更新、取消、恢复及动态失效均统一遍历清理。PageMap 把临时包裹视为透明，不改变原始路径与结构签名，沿用现有本地结果。恢复精确还原原 HTML。

具体方案、前后测量和回归命令见 [界面留白优化](compact-layout.md)。

## 数据与验证

本地 IndexedDB 包含 entries、cache、meta、trash、pages，不涉及云端数据库。v0.13.0 总结结果使用独立 dianyi-knowledge IndexedDB：visits、documents、snapshots、summaries、jobs、meta；旧 summaryResults 会话逻辑仅保留于兼容库测试，生产执行器始终使用持久知识层。词库按标准化原文与目标语言去重，列表每页 50 条；缓存最多 1000 条、约 7 天，删除与编辑会清理旧缓存。撤销 8 秒有效，后台启动清理过期记录。导出包含词句与经过清理的来源，不包含 Key、请求头或页面查询参数。

自动验证覆盖真实 MV3 注入、黑名单生效／恢复／重启、迁移保留、在途取消、权限与凭据边界、右键回调链路、原生选区和整页阅读。独立有界面浏览器另用真实操作系统菜单验收选区、整页、停用和恢复；结果见 verification/native-context-menu.json。

总结专项使用未修改 ZIP 与真实本地 HTTP/SSE，记录为 verification/summary-0.10.0.json；原生 Chrome 工具栏和右键已实点验证。未使用真实付费厂家 Key，原生 Edge 安装及物理宽度拖动尚未完成确认。

## 阅读知识执行链

导航先登记访问，正文可读后以事务保存快照、文档指纹、摘要和任务，再调用模型。页面身份由完整 URL 的摘要标识，正文版本单独计算；保存用的来源链接保留常用文章参数，移除认证和追踪字段。队列有界串行，服务重启将进行中的任务标记中断，尚未启动的任务续办，避免自动重跑已付费用量。

页面摘要与总结配置相同可复用，主动重新总结保留旧完成版本。页面上下文最多选择三条直接相关阅读；请求前递归复核来源与上下文的黑名单及权限。输入资料、用户备注和上层结论保存证据关系，删除沿依赖清理，旧流不能写回。

日结按配置时区自然日，默认 18:00 阶段归纳，晚到资料后续补齐版本。周／月按日结、年按月结归纳；大输入无损分批保留 ID，层级归纳有上限。周期签名使用语义范围、证据版本、备注、提示词及模型，而非当前时钟，重复闹钟和后台唤醒不重复请求。已采集资料尚未完成时延迟回顾；空资料不访问模型。

数据进入模型、写回及导出均检查来源策略。知识导出按白名单字段生成，不含配置或凭据；大批量导出超过传输边界时要求按筛选分批。完整行为见[阅读知识指南](knowledge-guide.md)。
