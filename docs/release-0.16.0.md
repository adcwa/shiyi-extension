# 点译 v0.16.0 更新说明

日期：2026-11-10

## 本次更新

- 打开释义卡片自动显示音标，无需再次点击“查看读音”。
- 内置 125,912 条离线美式读音，按首字母加载；本地命中不调用模型，没有总结模型也能使用。
- 英式、美式试听使用系统本地语音；发音说明和读音可复制，缺少语音时有添加提示。
- 本地未收录时使用已配置的总结模型补充音标与说明，按网页及语境缓存。未配置总结模型时显示未收录提示，保留试听。
- 同一处反复悬浮复用进行中的查询，关闭卡片后继续保存模型结果。导航、停用网站和取消任务仍可停止请求。
- 保留已有词库、偏好、模型连接和有效读音缓存；旧版“无法确定读音”缓存不阻挡内置词典查询。
- 包含 v0.15.0 后的可见区域翻译优先、块后加载提示、可拖动小宠物翻译进度、并行语境补充和复制改进。

## 权限和隐私

没有新增浏览器权限。字典、脚本和渲染器随包分发，不执行远程代码。系统试听不调用远程语音服务。公开隐私政策：

https://github.com/adcwa/shiyi-extension/blob/main/docs/privacy-policy.md

本地词典来源、版本、校验和和许可证见 `src/data/pronunciation/README.md` 与 `LICENSES.txt`。

## 安装与升级

- 商店用户：审核通过并发布后，由 Chrome 更新原扩展，保留原有本地数据。
- 本地用户：解压 `dianyi-chrome-edge-0.16.0.zip`，运行其中的“升级点译”，选择原目录；在扩展管理页重新加载原插件并刷新网页。不要先卸载或新建另一份插件。
- 商店上传使用 `dianyi-chrome-web-store-0.16.0.zip`；商店包根目录含 `manifest.json`，不含 `key` 字段。本地安装包保留固定身份字段。
- 未更改存储结构。回退程序时保留原扩展身份和浏览器数据，不卸载；商店回退按商店后台提供的版本回退流程操作。

## 商店测试说明

点译无须登录。核心模型请求使用评审可用的模型连接；请沿用后台已配置的受限测试凭据，不将 Key 写入说明、代码或安装包。

1. 在“词句库 → 导入”导入下列最小 JSON，目标语言使用中文；此测试不需 API Key。
2. 打开英文网页，找到 `engineer` 或 `orchestration`，悬浮已标记词。应直接显示美式音标，发音说明标明本地词典；无需总结模型。
3. 试听英音或美音；设备需要对应系统本地语音。没有语音包时，查看添加提示。检查复制读音、复制全部及关闭时停止朗读。
4. 页面加载完成后断网，再悬浮已标记单词，本地词典仍可显示。未收录短语且没有总结模型时，显示本地暂无音标并保留试听入口。
5. 配置支持 SSE 的通用总结模型后，查看未收录短语 `distributed systems`。应自动生成音标，反复悬浮复用进行中的请求；刷新后恢复缓存。已收录单词继续使用词典，不因已配置模型而增加请求。
6. 回归划词翻译、整页双语／仅译文与恢复原文，展开更多、复制译文／补充；总结侧栏的流式输出和制品导出。自动总结默认关闭，手动总结可用。

```json
{"format":"shiyi-vocabulary","version":1,"entries":[{"text":"engineer","translation":"工程师","targetLanguage":"zh-CN","kind":"word"},{"text":"orchestration","translation":"编排","targetLanguage":"zh-CN","kind":"word"},{"text":"distributed systems","translation":"分布式系统","targetLanguage":"zh-CN","kind":"phrase"}]}
```
