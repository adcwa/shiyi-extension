# 点译 v0.12.1 · 网页总结

2026-11-03 · 正式可安装插件功能

用自己配置的通用对话模型总结当前网页，在原生浏览器侧栏阅读流式结果。网页保留当前原文或译文显示方式；总结不逐句翻译，也不写入词句库。早期 `prototypes/page-summary/` 是固定示例原型，本文说明正式插件。

## 开始使用

1. 安装 `dianyi-chrome-edge-0.12.1.zip` 解压后的扩展，名称为“点译 · 翻译与网页总结”。首次安装步骤见随包安装与使用指南。
2. 点击工具栏点译图标，在最上方的“网页总结”点击“总结设置”，单独连接总结模型。
3. 回到普通 HTTP(S) 网页，等待正文加载。弹窗选择总结方式后点击“总结当前网页”，或右键“点译 → 总结当前网页”使用已保存的默认方式。
4. 原生侧栏打开即自动总结当前页，不再停留在操作引导。可停止、重新总结、复制全文、导出文档，或切到“制品”集中查看代码、表格、图形和公式。

侧栏按标签页独立开启：A 页打开不会把 B 页也开启，切回已打开的标签页继续查看其结果。侧栏可见时，刷新或跳转会等待新页加载后自动总结；关闭、隐藏或尚未打开侧栏的页面不自动请求模型。黑名单网站不提供侧栏，加入黑名单会关闭对应页侧栏并停止该页任务，其他页面不受影响。从黑名单恢复只重新提供入口，需要用户打开后才总结。

侧栏只承载总结内容、状态和制品操作，不放模型设置、提示词表单、翻译或词库。翻译与设置保留原入口：翻译连接为 `options.html#model`，总结配置为 `options.html#summary`。当前网页在黑名单中或浏览器未允许访问时，总结不能绕过限制；从原网站开关或浏览器权限恢复后再使用。

## 独立模型与提示词

总结设置支持常用厂家推荐型号、“其他模型（手动填写）”及自定义 Chat Completions 兼容服务。远端地址需 HTTPS，本机回环服务可 HTTP；无鉴权本机模型可选择“无需密钥”。总结服务需支持 SSE 流式响应。

| 项目 | 总结 | 翻译 |
| --- | --- | --- |
| 设置入口 | 总结设置 | 原模型连接 |
| 千问默认型号 | `qwen-flash`，通用对话 | `qwen-mt-flash`，专用翻译 |
| 凭据 | 独立总结 Key | 原翻译 Key |
| 默认保存 | 本次浏览器会话 | 本次浏览器会话 |
| 长期保存 | 单独明确勾选本机记住 | 单独明确勾选本机记住 |
| 请求正文 | 当前页主要可见正文 | 用户确认的选区或翻译块 |

两者即使使用同一厂家和端点也不串用 Key，清除总结密钥不影响翻译密钥。切换厂家或地域会清空尚未保存的 Key。总结拒绝 `qwen-mt-*` 型号，避免把翻译专用模型用于分析。连接测试发送固定短文验证真实流式响应，可能使用少量额度，不发送当前网页。

可设默认场景，分别编辑通用、技术、新闻、专业及调研提示词，每项最多 6000 字符，可恢复预设。保存只用于下一次总结，不自动重跑旧结果。高级设置的“无响应超时”支持 5／10／20／25 秒，指连续收不到响应的时长；流式输出持续到达时会刷新该计时。

## 场景与请求次数

| 场景 | 用途 | 正常请求数 |
| --- | --- | --- |
| 自动识别 | 先识别主题与类型，再选对应提示词生成 | 2 次：分类一次、流式总结一次 |
| 通用总结 | 核心观点、依据、结论与必要限制 | 1 次 |
| 技术总结 | 问题、原理、步骤、接口／代码与局限 | 1 次 |
| 新闻总结 | 事件、人物、时间地点、事实与各方立场 | 1 次 |
| 专业分析 | 判断、证据链、概念、风险与边界 | 1 次 |
| 调研分析 | 网页中方案／观点的比较、证据与待验证问题 | 1 次 |

输出使用简体中文 Markdown。自动识别只使用本次正文前 10,000 字符以内的摘录；分类结果不完整或类型无效时，显示说明并使用通用总结。选择场景、保存提示词、复制、导出和切换视图不请求模型。首次打开、侧栏可见期间的新页总结，以及主动重新总结会使用额度；同一页重新打开复用结果。连接失败或手动停止后保留结果，重新打开不自动重试，点击“重新总结”再次生成。

“调研分析”也只基于当前网页，不搜索其他网页，不补造来源、数字或结论。网页中的命令或角色声明作为待分析资料处理，不能替代总结指令。模型仍可能理解有误，关键结论应回到来源核对。

## 正文范围与原文保护

优先提取主文档的 `article`、`main`／主内容区域，缺少这些结构时读取页面可读内容。仅处理已加载、主要可见的正文，保留正文代码、列表和表格；排除表单输入值、可编辑区域、隐藏内容、导航、侧边栏及插件自身界面。不会自动滚动加载后续内容。浏览器内部页、扩展商店、内置 PDF、图片／Canvas 文字、iframe 和 Shadow DOM 暂不支持。

当前处于“仅译文”模式时，提取插件保存的原始文字，而不是把译文再次作为来源。总结不改写网页，也不切换翻译显示模式。与整页翻译跳过代码块不同，总结将主要正文中的代码和表格视为分析资料。

最多纳入前 60,000 字符；超过范围或提取节点预算时，侧栏明确显示截取提示，不把部分内容说成全文。来源标题与域名用于侧栏说明，正文请求不附加页面 URL、Cookie 或表单值。正文中本来可见的信息，包括代码，会发送给用户配置的总结服务。

## 流式阅读与恢复

- 生成时显示读取、识别主题或生成状态；点击“停止”中断实际请求并保留已收到的内容。断线、超时和服务错误同样保留部分结果，提供主动重新总结路径。
- 单任务最长 3 分钟，输出最多 8 万字符；达到边界会停止并说明现有结果未完整完成。无响应超时与整个任务时限分别计算。
- 向上阅读时不强制跳回底部，点击“有新内容 · 回到底部”恢复跟随。正文与制品视图保留各自的阅读位置。
- 刷新或切换来源会停止旧任务。当前标签页的侧栏可见时，等待新页加载后自动总结；隐藏期间只标记旧结果，回到可见侧栏后再总结新页。网页局部文字变化和无限滚动不触发自动追加请求，可按需点击“重新总结”。
- 本次浏览器会话最多暂存最近 8 页。同一页关闭再打开侧栏复用暂存，不重复请求；关闭期间刷新或跳转后，再打开会总结当前新页。完全退出浏览器后不承诺保留，关闭来源标签页会移除该页记录。需要长期保留时主动导出。

原生侧栏高度随浏览器窗口，宽度可通过浏览器分隔线调整，上下界由浏览器决定。内容已在 320／390／600px 宽度验证；物理拖动尚未完成自动化确认。原生关闭控件也由浏览器提供。

## 复制与导出

| 内容 | 复制内容 | 导出格式 |
| --- | --- | --- |
| 全文总结 | Markdown，含来源和完成状态 | `.md`、独立无脚本 `.html` |
| 代码 | 原始代码 | 按语言为 `.js`、`.ts`、`.py` 等，未知类型为 `.txt` |
| 表格 | Markdown 源码 | `.md`、`.csv` |
| Mermaid 图 | Mermaid 源码 | `.mmd`、`.svg` |
| 公式 | LaTeX 源码 | `.tex` |

停止、错误或截取后的导出明确标识部分结果。全文文档带去除查询参数和锚点的来源地址；不导出 Key 或鉴权头。CSV 对以公式触发字符开头的单元格添加保护，避免直接按公式执行。HTML 代码制品按文本处理，不输出可运行 HTML 文件；全文 HTML 是阅读文档，无脚本或远程资源。没有 Word 导出或交互图表运行环境。

代码围栏未闭合时先按源码显示；完整的代码、表格、Mermaid 和公式才进入相应制品。图形预览失败仍保留源码，可复制或导出，不执行模型返回的网页脚本。

## 本地渲染与隐私

渲染器随安装包本地分发，使用 markdown-it 15.0.3、Mermaid 12.2.0、KaTeX 0.19.1；没有 CDN 或远程字体。Markdown 原始 HTML 关闭，Mermaid 为 strict 且清理 SVG，公式使用 `trust: false` 和 MathML。Mermaid 依赖中的动态 CSV 编译已改为静态转换，满足 MV3 严格脚本策略。

模型调用在扩展后台执行，侧栏不直接访问模型服务，不持有明文凭据。总结与翻译凭据使用独立存储记录；默认会话保存，明确记住才写本机长期存储。这不是加密保险箱。结果和词库不上传点译服务器，也不使用追踪服务。
